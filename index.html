¿Qué es Flexbox?

Flexbox es un sistema de CSS que permite ordenar, alinear y distribuir elementos dentro de un contenedor de forma flexible.

Propiedades utilizadas

Se utilizaron display: flex, justify-content, align-items, gap y flex-wrap para organizar los distintos sectores de la página.
